# Frontend — Control de Inventario

Interfaz web construida con React y Vite para el sistema de inventario y trazabilidad de Constructora Del Valle.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Verificaciones

```bash
npm run lint
npm run build
```

## Vista previa de producción

```bash
npm run preview
```
